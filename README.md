## Differential Evolution with Constraints 🌱

هذا المشروع يعرض كيفية استخدام خوارزمية التطور التفاضلي (Differential Evolution – DE) لحل مسائل تحسين (Optimization Problems) مع قيود على المتغيرات، باستخدام مكتبة scikit-opt.

كما يوضح كيفية التعامل مع قيود المساواة واللاتساوي بطريقة عملية وواضحة.

## 🚀 الفكرة الأساسية

## 🛠️ المزايا

استخدام مكتبة scikit-opt لتبسيط بناء الخوارزمية.

التعامل مع قيود متعددة بطريقة سهلة.

مثال عملي وواضح لفهم أساسيات خوارزميات التحسين التطوري.

## 📂 محتويات المشروع

main.py → يحتوي على الكود الأساسي لتشغيل DE مع القيود.

README.md → شرح مبسط وسهل الفهم.

## ▶️ طريقة التشغيل

تثبيت المكتبة:

pip install scikit-opt


تشغيل الكود:

python main.py

## 📊 مخرجات متوقعة

عند التشغيل، سيطبع البرنامج أفضل حل وجدته الخوارزمية، مثل:

DE - best_x: [1.23, 0.4, 0.6]
DE - best_y: 2.13
